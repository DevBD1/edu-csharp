# Task 02 - SepetTutari Operator Overloading

## Gorev

`SepetTutari` sinifini operator overloading kullanarak tamamla.

## Senaryo

Bir e-ticaret sepetinde iki farkli tutar birlestirilecek ve indirim dusulecek.

## Beklenenler

- `SepetTutari(decimal tutar)`
- `operator +`
- `operator -`
- `operator >`
- `operator <`
- `yazdir()`

## Main

- Iki sepet tutari olustur
- Toplam tutari hesapla
- Indirim dus
- Iki tutari karsilastir
- Sonuclari yazdir

## Not

- Bu dosya sadece iskelet olarak basladi.
- Cozum kodunu sen yazacaksin.
