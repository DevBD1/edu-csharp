# Task 02 - Arac Copy Constructor

## Gorev

`Arac` sinifini constructor overloading ve copy constructor ile tamamla.

## Beklenenler

- `Arac()`
- `Arac(string marka)`
- `Arac(string marka, int modelYili)`
- `Arac(Arac diger)`
- `yasHesapla(int guncelYil)`
- `yazdir()`

## Main

- Bir `Arac` nesnesi olustur
- Bu nesneyi copy constructor ile kopyala
- Iki nesneyi de yazdir

## Not

- Bu dosya sadece iskelet olarak basladi.
- Cözüm kodunu sen yazacaksin.
